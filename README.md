# Sistema de Cadastro de Medicamentos

## Descrição
Este projeto é um sistema simples desenvolvido em Python para
gerenciar os medicamentos de uma farmácia.

## Como executar
1. Instale o Python no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto.
4. Execute o arquivo main.py.

## Funcionalidades principais
- Cadastrar medicamentos.
- Listar todos os medicamentos.
- Buscar medicamentos pelo nome.
- Salvar os dados em um arquivo CSV.
- Recuperar os dados ao iniciar o programa.

## Requisitos técnicos aplicados

- if, elif e else: utilizados para controlar as opções do menu.
- while: mantém o menu funcionando até o usuário escolher sair.
- Funções: utilizadas para cadastrar, listar, buscar,
  carregar e salvar medicamentos.
- Listas e dicionários: armazenam os medicamentos em memória.
- Arquivo CSV: guarda os dados para que não sejam perdidos.
- Git: utilizado para registrar as etapas do desenvolvimento.

## Tecnologias utilizadas
- Python
- Biblioteca padrão csv
- Git e GitHub
